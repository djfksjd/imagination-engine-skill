# Imagination Engine

Imagination Engine v0.5.1은 brief를 희생하지 않으면서 **쓸모 있고 비자명한
아이디어 포트폴리오**를 만드는 최소형 실험 스킬입니다.

## 권장 통합 플러그인

대부분의 사용자는 [`djfksjd/imagination`](https://github.com/djfksjd/imagination)을
설치하고 `$imagination`만 호출하는 방식을 권장합니다. 통합 플러그인이 이
엔진으로 아이디어를 제시하고 사용자 선택을 기다린 뒤, 다음 턴에
`imagination-brainstorming`으로 선택안을 구체화합니다.

아이디어 발산만 직접 호출하거나 엔진을 독립적으로 평가하려면 이 저장소를
단독 설치하면 됩니다.

이전의 제약 중심 파이프라인은 일반 프롬프트와의 블라인드 비교에서 두
번 패했습니다. 전체 구현은 연구 기록으로
[`legacy/v0.4.0/`](legacy/v0.4.0/)에 보존했으며 더 이상 런타임에서
로드하지 않습니다. 새 버전은 2026-07-29 사전 등록 holdout 평가에서
강한 일반 프롬프트 기준선을 통과했습니다.

## 달라진 점

- 런타임은 짧은 `SKILL.md` 한 장이며 생성 스크립트와 기계식 게이트가 없습니다.
- 적합성은 평균 점수의 한 항목이 아니라 탈락 조건입니다.
- 직접 답변, 원거리 메커니즘 전이, 전제 변경의 세 경로로 후보를 만듭니다.
- 서로 다른 아이디어를 억지로 혼합하지 않습니다.
- 절대 자기 점수 대신 후보 간 비교와 세트 전체의 다양성을 봅니다.
- 평가 하니스는 `evals/`에 분리되어 창작 문맥에 들어오지 않습니다.
- 검증 기간에는 자동 실행하지 않습니다. `$imagination-engine`으로 명시 호출합니다.

## 단독 설치

```bash
curl -fsSL https://raw.githubusercontent.com/djfksjd/imagination-engine-skill/main/install.sh | bash
```

사용 예:

```text
$imagination-engine을 사용해서 대화 선택지 없이 협상하는 게임 메커니즘
다섯 개를 제안해 줘. 플레이어는 결정 전에 결과를 이해할 수 있어야 해.
```

## 평가

[`evals/README.md`](evals/README.md)에 강한 일반 프롬프트 기준선, 개발
brief, 블라인드 비교 형식, 측정 지표와 keep/discard 규칙을 둡니다.
변경은 한 번에 하나만 적용하고, 설계가 고정된 뒤 확인 세트를 한 번
평가합니다.

인계 경계를 보완한 뒤 새로 만든 2026-07-29 `gpt-5.4` 확인 세트에서는
스킬 결과가 26 대 4로 선호됐고(86.7%, 95% Wilson 구간 70.3–94.7%),
적합성 `+0.37`, 유용한 의외성 `+0.90`, 세트 다양성 `+0.47`, 완성도
`+0.26`을 기록했습니다. 토큰 비용은 일반 프롬프트의 `1.10배`였습니다.
전체 설정과 한계는
[`evals/results/2026-07-29-gpt-5.4-confirmation-v2.json`](evals/results/2026-07-29-gpt-5.4-confirmation-v2.json)에
기록했습니다.

심사자가 서로 독립된 호출이지만 같은 모델 계열이므로 사람 평가를 대신하지는
않습니다. 자동 실행은 별도 트리거 정밀도 검증 전까지 꺼 두고 명시 호출합니다.

## 이전 버전

`legacy/v0.4.0/`에는 이전 스킬, 스크립트, 덱, 예제, 번역 문서와 300개
회귀 테스트가 보존되어 있습니다. 이 테스트는 내부 일관성을 검증하지만
창의적 품질을 검증하지는 않습니다.
